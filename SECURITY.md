## Reporting a Vulnerability

We take the security of our project and the protection of API credentials very seriously. If you discover a security vulnerability within this service, please follow these guidelines:

### 🚨 Do NOT disclose publicly
Please **do not** open a public GitHub issue or discussion for security vulnerabilities, as this could expose sensitive information before a patch is released.

### How to report
Instead, please report vulnerabilities privately:
- **Email:** Send details directly to the maintainer via GitHub profile contact or create a private security advisory directly in the repository via the **Security** tab -> **Advisories** -> **Report a vulnerability**.

### What to include in your report
To help us investigate and fix the issue as quickly as possible, please include:
- A description of the vulnerability and its potential impact.
- Steps or a proof-of-concept to reproduce the issue.
- Any relevant logs, configuration details, or affected endpoint routes.

### What to expect
- **Acknowledgment:** You can expect an initial response within **48 hours**.
- **Updates:** We will provide regular updates as we investigate and develop a fix.
- **Coordination:** Once a fix is verified, we will coordinate the public disclosure and credit you for the discovery (if desired).
